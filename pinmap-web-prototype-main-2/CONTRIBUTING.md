# 함께 개선하기

1. GitHub Issue에 화면 이름, 개선 목적, 완료 조건을 적고 담당자를 정합니다.
2. `git switch -c feature/작업이름`으로 작업 브랜치를 만듭니다.
3. 로컬에서 실행하고 모바일 402×874와 넓은 화면에서 확인합니다.
4. 변경 화면 캡처와 테스트 결과를 포함해 Pull Request를 엽니다.
5. 다른 팀원이 검토한 뒤 main에 합칩니다.

`main`에 합쳐진 변경은 연결된 Vercel 프로젝트에서 자동 배포됩니다. 배포 결과는 [핀맵 프로토타입](https://pinmap-prototype.vercel.app/)과 Vercel의 Deployments 화면에서 확인하세요. 이 저장소는 웹 프로토타입용이며 네이티브 앱 실험 코드는 별도 저장소에서 관리합니다.

저장·수정 후 새로고침 유지, 온보딩 4단계(열 때마다 표시)와 관심사에 따른 홈 구성, SNS 공유 저장 체험(case1·case2·실행 취소), 마이 설정·알림, 검색·필터, 지도 핀, 장소 확인 필요, 원본 삭제 상태를 확인하세요.
실제 개인정보·API 키를 예시 데이터나 코드에 넣지 마세요. 외부 콘텐츠를 추가할 때 출처와 사용 범위를 확인합니다.
