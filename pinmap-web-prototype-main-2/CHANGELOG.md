# 핀맵 프로토타입 수정 내역 (10/5)

## 1. 온보딩 (페이지를 열 때마다 전체 화면, 4단계)
- 서비스 소개 → 가져오는 방법(공유 → 핀맵) → 관심사 선택 → 맞춤 준비 순서예요.
- 고른 관심사에 따라 홈 구성이 바뀌어요.

## 2. SNS 공유 → 핀맵 저장 체험 (저장 과정 시안 반영)
- 예시 SNS 게시물에서 공유 → 핀맵을 누르면 저장 시트가 올라와요.
- 저장 시트에는 AI 자동 분류(기본 켜짐), 카테고리, 모음(선택)이 있어요.
  - case1: 바깥을 누르면 AI 분류로 저장돼요.
  - case2: 카테고리나 모음을 직접 고르면 그대로 저장돼요.
- 저장 후 "핀맵에 저장됨" 배너가 뜨고, 보기와 실행 취소를 할 수 있어요.

## 3. 서비스 정보 반영
- 카테고리를 맛집·카페 / 전시·팝업 / 여행 / 쇼핑 / 레시피 / 생활 정보 / 기타로 바꿨어요.
- 장소형(맛집·카페, 전시·팝업, 여행)은 지도에 표시돼요. 나머지는 갤러리형 카드로 보여줘요.
- 상세 화면은 유형별로 달라요. 장소는 길찾기, 전시는 기간, 쇼핑은 가격, 레시피는 간단 정보를 보여줘요.
- 하단 메뉴는 홈 · 지도 · 저장함 · 마이예요.
- 홈 상단에 현재 위치(📍 성수동)를 표시해요.

## 4. 마이 · 알림 (10/6)
- 계획하기 탭을 없애고 마이 탭을 만들었어요.
  - 프로필, 저장 통계, 온보딩에서 고른 관심사(변경 가능), 내 모음, 카테고리별 저장
  - 설정: 알림, AI 자동 분류 기본값, 위치 권한, 길찾기 지도 앱, 온보딩 다시 보기, 데이터 초기화
- 마이 화면 상단은 핀맵 로고 대신 ‘마이’ 제목을 보여줘요.
- 오른쪽 상단을 알림 버튼으로 바꿨어요. 마감 임박·주변 장소·장소 확인 필요 알림을 보여줘요.
- 홈의 + 버튼과 영어 서브 문구(PINMAP · FOR YOU 등)를 뺐어요.
- 콘텐츠 카드에서 SNS 이름(Instagram 등)을 빼고 저장 시점만 보여줘요. SNS 출처는 상세 화면에서 확인해요.
- 각 화면 제목 아래 서브 문구를 뺐어요.
- 앱을 켜지 않아도 현재 위치에 맞춰 저장 콘텐츠를 추천하는 푸시 알림을 잠금화면 미리보기로 만들었어요.
  - 조건: 푸시 알림 허용 + 위치 권한 ‘항상 허용’ + 현재 위치 기반 추천 알림 켜짐 (마이 > 설정)
  - 성수동·서울숲·강릉 등으로 이동하면 근처 저장 콘텐츠 알림이 오고, 누르면 상세가 열려요.
- 마감이 임박한 콘텐츠는 홈 상단(현재 위치 아래, 제목 위)에 배너로 보여줘요. 누르면 상세로 가고, X로 닫을 수 있어요.

## 5. 디자인
- 글꼴을 전체 Pretendard로 바꿨어요.
- 키 컬러 #51DDA1은 그대로 유지했어요.

## 참고
- app.js가 거의 새로 작성됐어요. 따로 작업 중인 분은 합치기 전에 확인해 주세요.
- 공개 사이트는 재배포해야 반영돼요.
- 논의가 필요해요: 모음을 골랐을 때 저장 시트가 바로 닫힐지 여부

## 홈 화면 수정 (10/10)
- 온보딩이 끝나면 홈 화면 코치마크 튜토리얼(4단계)을 보여줘요: 내 동네 → 관심사 홈 → SNS 저장 → 하단 메뉴. 건너뛸 수 있어요.
- 홈 상단 '필요한 순간, 다시 꺼내드릴게요.' 문구를 뺐어요.
- 영감 카드 제목을 '막힐 때 보는 영감 모음' 한 줄로 줄였어요.
- 홈 상단 현재 위치를 '내 동네'로 바꿨어요 (최대 2개, 기본: 성수동 · 청파동).
  - 메인 동네는 검정 큰 글씨, 서브 동네는 회색 작은 글씨. 서브를 누르면 자리가 바뀌어요.
  - 메인 동네를 누르면 '내 동네 설정' 시트에서 추가 · 수정 · 삭제할 수 있어요. 동네가 1개면 ⌄ 표시가 붙어요.
  - '지금 내 주변' 섹션은 메인 동네 기준으로 바뀌어요.
- 새 파일: place.js · place.css(내 동네), coach.js(튜토리얼)

- 내 동네 설정 시트가 넓은 화면에서도 화면 아래에서 올라와요.
- 튜토리얼 중에는 화면이 스크롤되지 않아요(강조할 위치로만 자동 이동).
- 마이 화면의 연한 초록빛 회색 배경을 흰색·연한 회색으로 바꿨어요.
- 홈 관심사 키워드를 7개 모두 보여주고, 누른 키워드만 홈에 표시해요. 기본값(온보딩·마이에서 정한 관심사)은 켜진 채로 앞에 오고, 홈에서 바꾼 건 저장되지 않아 다시 열면 기본값으로 돌아와요. '기본값으로'로 되돌릴 수 있어요.

## 홈 · 마이 · 하단 메뉴 수정 (10/10 저녁)
- 홈 카드를 모두 같은 크기 2열 격자로 바꿔 줄마다 위아래가 맞아요.
- 홈 주제 제목 앞 이모지를 빼고 한 단계 굵게(700) 했어요.
- 관심 키워드를 눌러도 상단 동네 글자가 흔들리지 않아요(동네를 바꿀 때만 움직임).
- 관심사별 추천 카드 제목을 모두 한 줄로 줄이고, 좌우로 넘겨 다른 관심사 카드를 볼 수 있어요(아래 점 표시).
- 관심 키워드는 최대 3개(온보딩 · 홈 모두).
- 'SNS에서 바로 저장해보기'를 홈에서 빼고 마이로 옮겼어요.
- 마이 구성 변경: 프로필(닉네임) · 저장 통계 · SNS 저장 체험 / 나의 핀맵(내 동네 · 관심사) / 설정(알림 · 저장 · 위치·지도는 하단 시트) / 도움말 / 로그아웃
- 하단 메뉴 아이콘 아래 문구: 홈 · 지도 · 저장됨 · 계획 · 마이 (navlabels.js)
- 튜토리얼은 온보딩을 처음부터 봤을 때만 나오고, 마이 > 도움말에서 다시 볼 수 있어요.
