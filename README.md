# 핀맵 (pinmap)
사용자경험디자인II (26-2)

**[공개 프로토타입 실행](https://pinmap-prototype.vercel.app/)** — 링크를 아는 누구나 접속할 수 있습니다.

이 저장소는 Vercel의 `pinmap-team/pinmap-prototype` 프로젝트에 연결하는 웹 프로토타입 원본입니다. `main`에 합쳐진 변경 사항이 공개 사이트에 반영되도록 Git 배포를 사용합니다.

저장 콘텐츠를 다시 발견하는 HTML 기반 모바일 웹앱 프로토타입입니다. Material 3의 색상 역할과 카드·내비게이션 패턴을 참고했으며 키 컬러는 `#51DDA1`, 글꼴은 Pretendard입니다. 402×874 모바일 화면을 기준으로 좁은 화면에 반응하고 PC에서는 앱 형태로 가운데 표시합니다.

### 실행

별도 빌드나 패키지 설치 없이 저장소 폴더에서 실행합니다.

```sh
python3 -m http.server 8080
```

브라우저에서 http://localhost:8080 을 엽니다. `index.html`을 직접 열 수도 있지만 저장 기능을 안정적으로 테스트하려면 위 로컬 서버를 권장합니다.

### 구현 기능

- 페이지를 열 때마다 전체 화면 온보딩 4단계: 서비스 소개(로딩) → 콘텐츠 가져오는 방법(공유 → 핀맵 3-step) → 관심사·활용 목적 복수 선택 → 맞춤 준비(로딩)
- 온보딩에서 고른 관심사 순서대로 홈 구성 변경: 첫 관심사 배너, 관심사별 섹션, 마감 임박·저장 수 많은 콘텐츠·최근 저장, 홈의 ‘관심사 변경’으로 다시 선택
- 홈·지도 상단 현재 위치 표시(📍 성수동 · 예시 위치, 위치 권한 체험)
- 홈 마감 임박 배너: 현재 위치 아래·제목 위에 가장 임박한 콘텐츠 표시, 누르면 상세, 닫기 가능
- 콘텐츠 카드에는 저장 시점만 표시하고 SNS 출처는 상세에서 표시
- **SNS 공유 → 핀맵 저장 체험**: 예시 SNS 게시물 → 공유 버튼 → 공유 시트 → ‘공유 대상…’ → 앱 목록에서 핀맵 → 핀맵 저장 시트 → 게시물 하단 저장 배너(보기·실행 취소)
  - 저장 시트: 열리는 순간 ‘핀맵에 저장됨’ 상태, AI 자동 분류 토글(기본 켜짐), 카테고리 칩, 모음(선택)
  - case1: 바깥을 누르거나 ‘완료’ → 지금 상태(AI 분류)로 저장
  - case2: 카테고리 칩을 직접 고르면 AI 분류가 꺼짐 / 모음의 + 를 누르면 체크 후 시트가 내려감 (카테고리와 모음은 별개)
- 저장 카테고리: 맛집·카페, 전시·팝업, 여행(지도 표시) / 쇼핑, 레시피, 생활 정보, 기타(갤러리형 카드)
- 유형별 상세: 장소·거리·외부 지도 길찾기 / 전시 운영 기간·마감 / 쇼핑 가격·판매처 / 레시피 간단 정보 + 원본 콘텐츠 보기, AI 분류·직접 분류 표시
- 저장함 검색·카테고리 필터, 비장소 카테고리는 갤러리 보기
- 마이 탭: 프로필(닉네임·자주 가는 지역), 저장 통계, 온보딩에서 고른 관심사(변경 가능), 저장 방법 다시 보기, 내 모음, 카테고리별 저장, 설정(알림 3종·AI 자동 분류 기본값·위치 권한·길찾기 지도 앱·온보딩 다시 보기·데이터 초기화)
- **앱 밖 위치 기반 푸시 알림(잠금화면 미리보기)**: 마이에서 푸시 알림 허용(시스템 권한 창) + 위치 권한 ‘항상 허용’ + 현재 위치 기반 추천 알림이 켜져 있으면, 앱을 켜지 않아도 이동한 위치 근처의 저장 콘텐츠를 알림으로 추천. 마감 임박 → 온보딩 관심사 → 가까운 순으로 고르고, 알림을 누르면 해당 콘텐츠 상세가 열림. 조건이 안 맞으면 알림이 오지 않는 이유와 바로가기 표시
- 상단 알림 버튼: 마감 임박·주변 저장 장소·장소 확인 필요·다시 보기 알림(예시), 안 읽은 개수 표시, 마이 설정에 따라 켜고 끔
- 링크 붙여넣기 저장(AI 자동 분류 기본), 제목·카테고리·주소·메모·모음 수정
- 장소 확인 필요 상태: 주소 확인 전 지도 제외, 주소 입력 후 지도 포함
- 원본 삭제 상태: “삭제된 게시물입니다” 표시, 장소 정보와 메모 유지
- 브라우저 localStorage 저장: 새로고침 후 유지

### 구현 범위

실제 AI 분석·SNS 수집·GPS는 연결하지 않습니다. 지도 배경은 OpenStreetMap 타일을 사용하지만 표시되는 장소와 거리·마감·저장 수는 예시 데이터입니다. 관심사 추천은 간단한 로컬 규칙이며 실제 AI 개인화는 아닙니다. 일러스트는 직접 만든 SVG이고 기존 샘플 원본 버튼은 안내를 표시합니다. 사용자가 직접 저장한 HTTP(S) 링크만 원본을 엽니다. 실제 SNS 공유 메뉴는 웹에서 연결할 수 없어 예시 SNS 화면으로 저장 과정을 재현하며, 실제 SNS 로고·화면은 사용하지 않습니다. 웹 프로토타입은 앱이 꺼진 상태에서 위치를 확인하거나 휴대폰 알림을 보낼 수 없어, 앱 밖 푸시 알림은 잠금화면 미리보기로 재현합니다(실제 구현에는 네이티브 앱의 백그라운드 위치·지오펜싱과 푸시 서버가 필요). AI 분류는 제목 키워드 기반의 간단한 규칙입니다.

온보딩은 페이지를 열거나 새로고침할 때마다 처음부터 표시되며, 이전에 고른 관심사는 3단계에 미리 선택돼 있습니다. 앱 안에서는 홈의 ‘관심사 변경’ 또는 상단 ‘핀’ 버튼으로 다시 볼 수 있습니다. 이전 버전(`pinmap.v1`, `pinmap.v2`)에 저장한 콘텐츠는 새 카테고리로 변환되어 유지됩니다(장소 → 맛집·카페/전시·팝업/여행, 상품 → 쇼핑, 글·영상 → 생활 정보).

데이터는 사용자별 브라우저에만 저장되어 팀원과 자동 공유되지 않습니다. 공동 데이터 편집에는 별도의 서버가 필요합니다. 사이트 데이터 삭제 시 예시 상태로 초기화됩니다. Pretendard(jsDelivr CDN)에 연결할 수 없으면 시스템 한글 글꼴로 표시합니다.
